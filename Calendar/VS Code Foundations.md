2. Matching Text Selection

If you have a word highlighted, you can quickly find and edit other identical text strings: [[1](https://stevekinney.com/courses/visual-studio-code/vscode-multiple-cursors)]

|Action|Windows / Linux|macOS|
|---|---|---|
|**Select Next Occurrence** (Add next matching word)|`Ctrl` + `D`|`Cmd` + `D`|
|**Select All Occurrences** (Add cursors to every match)|`Ctrl` + `Shift` + `L`|`Cmd` + `Shift` + `L`|
|**Undo Last Selection** (If you selected one too many)|`Ctrl` + `U`|`Cmd` + `U`|
|**Skip Next Occurrence** (Skips a match without selecting it)|`Ctrl` + `K`, then `Ctrl` + `D`|`Cmd` + `K`, then `Cmd` + `D`|

3. Vertical Column Selection (Keyboard Only)

To quickly stack cursors directly above or below your current position: [[1](https://www.youtube.com/shorts/qT1QPWgkSFs), [2](https://www.youtube.com/watch?v=19_BG-gQ9QM&t=9)]

- **Windows / Linux:** `Ctrl` + `Alt` + `Up Arrow` / `Down Arrow`

- **macOS:** `Option` + `Cmd` + `Up Arrow` / `Down Arrow`

- _Alternative for macOS (depending on system shortcuts):_ `Cmd` + `Option` + `Shift` + `Up Arrow` / `Down Arrow` [[1](https://dev.to/sym/multi-select-in-visual-studio-code-19k2), [2](https://www.youtube.com/shorts/vJvF7Y9oEjc), [3](https://www.youtube.com/shorts/qT1QPWgkSFs), [4](https://www.youtube.com/watch?v=19_BG-gQ9QM&t=9), [5](https://stackoverflow.com/questions/29953479/how-can-you-create-multiple-cursors-in-vs-code)]


## Keyboard Shortcuts

### General

- `Ctrl + P` / `Cmd + P`: Quick file navigation.
- `Ctrl + Shift + P` / `Cmd + Shift + P`: Open Command Palette.
- `Ctrl + B` / `Cmd + B`: Toggle sidebar visibility.

### Editing

- `Ctrl + /` / `Cmd + /`: Toggle line comment.
- `Alt + Up/Down Arrow` / `Option + Up/Down Arrow`: Move line up or down.

### Navigation

- `Ctrl + G` / `Cmd + G`: Go to line.
- `Ctrl + Tab` / `Cmd + Tab`: Switch between open files.

### Debugging

- `F5`: Start debugging.
- `F9`: Toggle breakpoint.
